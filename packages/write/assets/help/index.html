MDEdit Help

Welcome to MDEdit

MDEdit is a Markdown editor for writing books. Each book lives in a project, you edit it one chapter at a time, and you can export an EPUB, print PDF and Word file ready for Kindle Direct Publishing. Projects stay in step across your PC and phone through Google Drive.

Quick start

  1. File → New Project… (Ctrl+Alt+N), pick a template and name it. See Projects.
  2. Create a file (Ctrl+N) and start writing. Each # Heading 1 starts a new chapter in the file list. See Files and chapters.
  3. Set a word goal under File → Project Progress…. See Goals and progress.
  4. When the draft is done, right-click the file → Mark for Export, fill in Book Details, then Export… (Ctrl+E).

Projects

A project is a folder with the subfolders you choose, kept inside your Root Folder (set in Settings). The Projects home shows each project as a card with its status, word count and goal progress.

Create and switch

  • New Project… (Ctrl+Alt+N): choose a template (Novel, Series, Short story or Blank). The template decides which subfolders are made (for example a notes or characters folder).
  • Switch Project… (Ctrl+K): type to jump to another project. Projects Home returns to the cards.
  • Open Folder… (Ctrl+O) opens any folder of Markdown files, even outside the Root Folder, as a plain folder.

On the Projects home

Search, sort, filter by status, archive or duplicate a project. Status is one of the project's settings; setting it to Editing turns on the editing stage.

Project Settings

File → Project Settings… holds the status, the folder layout and project-wide defaults for export. Project defaults sit between app settings and each book's own settings (see Settings layers).

Files and chapters

The file tree on the left lists your folders and Markdown files. Under each file it lists its chapters, split by # Heading 1 by default (change the level in Settings). Click a chapter to open it; only that chapter is loaded into the editor, so long manuscripts stay fast.

Tree toolbar

File and Folder create new ones, Import brings in Word documents, and Ctrl+P filters the tree by name.

Right-click a folder

New File Here, New Folder Here, Import Word Document, Rename (F2), Delete Folder (Del), Show in File Explorer.

Right-click a file

Mark for Export / Export… / Book Details… / UnmarkSee Export for KDP and Book Details.
Active ManuscriptTells MDEdit which file is the book. Goals, progress and sharing use it.
Analyze TextSee Text analysis.
Rename, DeleteDeleted files go to the Recycle Bin. Undo can bring back chapters.

Right-click a chapter

  • New Chapter Below… adds a chapter after this one.
  • Move Up / Move Down (Alt+↑ / Alt+↓) reorders chapters.
  • Rename (F2) changes the chapter's heading; Delete Chapter… (Del).
  • Mark Edited, Mark Edited to Here, Unmark Edited: see Editing stage.

Example: to reorder chapter 7 before chapter 6, select chapter 7 in the tree and press Alt+↑ once. The file's text is rearranged for you.

Writing and formatting

Edit in the formatted (Visual) view, or switch to raw Markdown with Ctrl+Shift+M (Source). Both edit the same text. The toolbar above the text offers bold, italic, headings, quotes, lists, scene break, undo and alignment; select text for a floating toolbar.

Markdown you will use most

# Chapter title            (Heading 1: starts a chapter)
## Section heading
**bold**   *italic*   ~~strike~~
> A quote
- bullet      1. numbered
* * *                      (a scene break)

Scene breaks

A line containing * * * (or ---) is a scene break. Insert one from the toolbar and jump between them with Ctrl+↓/Ctrl+↑ (see Moving around). They are printed as a break in the export and ignored by text analysis.

Source vs Visual

Use Source for exact control of the Markdown (alignment fences, comments, odd formatting), with a line-number gutter and Ctrl+G to go to a line. Use Visual for writing.

Zone Mode

View → Zone Mode (F8) hides the surrounding panels so you can write without distraction.

Word counts

The status bar shows the word count of what you are editing. Totals used by goals ignore headings' markup, comments and alignment fence lines.

See also: Alignment · Find and replace · Safety and autosave

Alignment

Body text is justified in the exported EPUB, print PDF and Word file. To line a part up differently, select the paragraphs and press an alignment button, or use the keys:

LeftCentreRightJustify
Ctrl+Shift+LCtrl+Shift+ECtrl+Shift+RCtrl+Shift+J

Pressing the alignment already in force removes it. In the file it is stored as a fence:

::: center
A centred title or verse,
as many paragraphs as you like.
:::

Fences can hold paragraphs, headings, quotes and lists, and do not nest. After a quote or list, leave a blank line before the closing :::.

To change what unfenced paragraphs do for the whole book (justified or left/ragged right), set Body text alignment in Book Details → Export.

Find and replace

  • Ctrl+F Find, Ctrl+H Find & Replace, F3 / Shift+F3 next / previous match.
  • Search the current chapter or the whole file.
  • In the find bar: Alt+C match case, Alt+W whole word, Alt+R regular expression.

Examples

To hunt overused words across the whole book, Analyze Text lists them for you, then use Find (whole file) to fix each one.

Tabs

Each open file has a tab. Ctrl+W closes the current tab; Ctrl+Tab cycles. MDEdit remembers your open tabs and window position between sessions. Analysis reports open in a tab too, see Text analysis.

See also: Moving around · Safety and autosave

Safety and autosave

  • Drafts. What you type is saved as a draft as you go, so a crash or power cut doesn't lose it; MDEdit offers to restore it next time. Press Ctrl+S to save to the real file.
  • Outside changes. If the file is changed by another program, MDEdit notices and asks how to proceed rather than overwriting.
  • Recycle Bin. Deleted files and folders go to the Windows Recycle Bin.
  • Undo for structure. See Undo.
  • Sync conflicts keep both versions. See Google Drive sync.
See also: Undo · Troubleshooting

Undo and redo

  • Ctrl+Z / Ctrl+Y undo and redo typing in the editor.
  • Ctrl+Alt+Z / Ctrl+Alt+Y (Edit → Undo Last Action) undo and redo the last chapter or file action: deleting, moving or adding chapters. It remembers the last 5.

Deleted a chapter by mistake? Press Ctrl+Alt+Z before doing anything else.

See also: Safety and autosave · Files and chapters

Goals and progress

Open File → Project Progress…. Set a word-count goal and a deadline for the project's active manuscript. You get a day-by-day chart, the words per day still needed, and an estimated finish date. Project cards on the Projects home show the same progress.

Example: a 90,000-word goal due in 60 days shows 1,500 words/day. If you write 2,000 a day the estimated finish moves earlier.

See also: Projects · Editing stage

Editing stage

Set a project's status to Editing (see Project Settings) to track your revision pass. Then:

  • Moving on from a chapter asks Mark Edited? (answer Not Yet to skip; it is not asked again until you save).
  • Right-click a chapter: Mark Edited, Unmark Edited, or Mark Edited to Here to mark it and every earlier chapter in the file.
  • The tree and project card show how far through the book you are.

Finished the first 12 chapters on paper? Right-click chapter 12 → Mark Edited to Here.

See also: Review with AI · Goals and progress

Comments and suggestions (Notes)

Select text (right-click it on the PC) and choose:

  • Add comment… to leave a remark on the passage.
  • Suggest a change… to propose replacement text (one paragraph at a time).

The Notes panel lists every note with its author. Accept a suggestion to apply it to your chapter, or reject it; mark a comment Resolved. Notes can have an optional Topic (for example Pacing) and can be filtered by author, topic, or to the chapter you are reading. A note stays with its text as you edit; if the text is deleted, the note is marked Resolved.

Notes come from you, from human reviewers and from AI reviewers (marked with an AI badge).

See also: Review with others · Review with AI

Review with others

Get feedback from people with their own MDEdit. It uses Google Drive, so sync must be set up on both sides.

  1. Set the project's Active Manuscript (right-click the file). Reviewers see only that book.
  2. Open Notes → Share… and create a link for each reviewer.
  3. Tick the chapters that reviewer should get (All/None above the list). Your ticks are remembered. Ticking everything shares the whole book.
  4. Send them the link or the short invitation with the download link for MDEdit.

Reviewers open it under Projects → Shared with me, read your latest text and add their own notes. You see everyone's together; they never see each other's. Projects → Sharing lists all your shares and lets you manage or remove links.

See also: Work on a book together · Comments and suggestions · Google Drive sync

Work on a book together

Let another author edit the same project. In Notes → Share… choose Collaborator (can edit) before Create editable link. They open it like a reviewer's link, under Projects → Shared with me.

  • A collaborator gets every Markdown file in the project and can edit them and create new ones. Reviewers still see only the Active Manuscript.
  • The chapter ticks limit only the Active Manuscript for a collaborator; every other file is shared whole.
  • Each time either of you syncs, both sets of changes are merged chapter by chapter and paragraph by paragraph. If you both changed the same lines, both versions are kept between <<<<<<< and >>>>>>> lines for you to settle.
  • You and your collaborators see each other's notes, including AI notes; collaborators can use Notes → AI… on their own copy. Reviewers' notes stay private to you.
  • Deleting or renaming a file isn't passed on (the other copy brings it back), and chapter order isn't merged. Changes pass between collaborators through your copy, so your MDEdit needs to be open and online.
See also: Review with others · Google Drive sync

Review with AI

Let Claude, GPT or another AI app read your chapters and leave comments and suggestions as a reviewer. The AI can never change your text; you accept or reject each note, and Accept all applies one reviewer's suggestions after a confirmation.

Set up

  1. Open a project and choose Notes → AI…, then Save files to Downloads. You get a MDEdit AI Kit folder with a README.
  2. Claude Desktop: double-click mdedit.mcpb to install the extension, and upload the three skill zips under Settings → Capabilities → Skills.
  3. Claude Code, Codex and other MCP apps: use the ready-made settings in the kit.

Ask for an edit

Do a line edit of the chapters in my project The Lost King.
SkillWhat it does
Developmental editComments on structure, pacing, stakes, continuity and character.
Line editOne-click suggestions for sentence-level fixes, plus comments on patterns.
Copy editExact corrections for spelling, grammar, punctuation, consistency.

Skills follow your style sheet and notes in the project. Notes are signed with the AI and skill (for example "Claude · Line edit"), and one skill's notes can be removed in a go from Notes → AI…. AI notes appear within seconds and stay on the PC where they were written.

Web-only apps (ChatGPT app, claude.ai) can't reach your PC. Notes → AI… → Online apps can open a token-protected door for them if you also set up a tunnel; read the risks in the AI-REVIEW document before using it. The phone app has no AI review.

Text analysis

Right-click a manuscript → Analyze Text. It runs in the background and writes <name> - Analysis.md beside the file, opening in a new tab without taking focus. Running again makes Analysis 2.md so you can compare drafts.

The tab shows a formatted report with Save as HTML, Save as PDF and Edit as Markdown (the Report button returns). It covers:

  • Dialogue share and speech tags; sentence length and rhythm; reading level.
  • Repeated words, echoes and phrases; adverbs; passive voice.
  • Filler, filter and crutch words; point of view and tense consistency; head-hopping.
  • Character mentions and where they appear; punctuation habits.

The Summary lists what is "worth a look" (for example average sentence over 22 words, more than 12 adverbs per 1,000 words, over 15% passive). These are guides for fiction, not rules, and some false positives are expected. Re-run it after editing; the page shows stored results.

Typical use: run it on a finished draft, jump to the Filler, filter and crutch words section, then use Find across the whole file to trim "just" and "really".

See also: Find and replace · Review with AI

Import from Word

Right-click a folder → Import Word Document…, or use the Import button above the file tree. Choose one or more .docx files; each becomes a Markdown file of the same name in that folder (a taken name becomes Name (2).md).

Headings (including Title) become # headings; bold, italic, strikethrough, links, lists, quotes and tables are kept. Windows app only. After importing, check the chapter list: each # heading is a chapter.

See also: Files and chapters · Export for KDP

Export for KDP

  1. Right-click a .md file → Mark for Export. Your manuscript is never modified; the book's details are saved beside it.
  2. Fill in Book Details.
  3. Export… (Ctrl+E): check the title and author, choose outputs and the save folder, and export.
OutputWhat you get
EPUB 3Passes the standard EPUB checker, with embedded fonts.
Print PDFExact KDP trim size (5 × 8 up to 8.5 × 11 in), mirrored margins with the right inside margin for your page count, chapters starting on right-hand pages, page numbers and a contents page.
DOCXA clean Word file with a linked contents list.

Fonts: EB Garamond, Crimson Pro and Libre Baskerville come with the app; the print PDF can use any font installed on your computer. Text alignment is carried into all three.

Not included: the paperback cover PDF, ISBN barcodes and uploading to KDP. The phone app has no export.

See also: Book Details · Settings layers · Alignment

Book Details

Right-click a marked file → Book Details…, or open it from the Export dialog. Sections:

  • Title page: title, subtitle, author, optional cover image (JPEG or PNG).
  • Copyright page, Dedication, Epigraph.
  • Back matter: Continue the Story, Also by the author (with a blurb for each book), About the Author, and a Custom page. Only links you type are ever added.
  • Chapters and Text: chapter heading style, fonts, size, spacing, body text alignment, trim size and margins for each output.
See also: Settings layers · Export for KDP

Settings layers

Export settings apply in this order: App (Settings) → Project (Project Settings) → Book (Book Details). A book changes only the fields you edit, so updating a project default reaches every book that hasn't set that field.

Each field shows where its value comes from; Reset hands it back to the layer above.

Example: set the font to Crimson Pro in Project Settings once. Every book inherits it, except one where you picked EB Garamond in its Book Details.

See also: Export for KDP · Settings

Google Drive sync

Open File → Google Drive Sync… and sign in once on each device. MDEdit keeps your projects in an MDEdit folder in your Drive and can only see files it created there.

  • Edits sync a few seconds after you save and when you return to the app.
  • If two devices change the same chapter, both versions are kept as a conflict copy for you to merge.
  • Nothing is deleted in bulk without asking: a pass that would remove many files waits for your go-ahead.

Don't put your Root Folder inside OneDrive, Dropbox or Google Drive for Desktop; two sync tools will fight.

See also: On your phone · Review with others · Safety and autosave

On your phone (Android)

The Android app has the same editor, Projects home, goals and find and replace. Files stay on the phone and sync through Google Drive.

  • Press and hold a file or project for its menu.
  • Press and hold text to select with Android's own handles. A bar above the keyboard then offers Cut, Copy, Paste, Comment, Suggest and Find. With nothing selected it offers bold, italic, headings, lists, scene break, alignment and undo.
  • No KDP export and no AI review on the phone; you can still read and add notes and share.
See also: Google Drive sync · Comments and suggestions

Settings

File → Settings… (Ctrl+,) holds app-wide choices: the Root Folder where projects live, the chapter heading level, appearance and colours, and the default export settings (the first of the settings layers). A button puts everything back to the shipped defaults; nothing is saved until you press Save.

View → Theme chooses Match Windows, Light or Dark. View → Zoom (Ctrl++, Ctrl+-, Ctrl+0) resizes the whole window. F11 toggles full screen.

Troubleshooting

ProblemTry
My chapter list is wrong or has a missing chapterChapters start at the heading level set in Settings (Heading 1 by default). Check the heading has a space after #, then press F5.
I can't find Export / Book Details for a fileRight-click the file and choose Mark for Export first (Export for KDP).
A file changed while I had it openAnother program or device edited it; see Safety and autosave. Sync conflicts keep both copies (Google Drive sync).
Sync is stuck or asks to confirm deletionsOpen Google Drive Sync… to read the message and confirm or cancel. Keep the Root Folder out of other sync tools.
Reviewer sees the wrong bookSet the Active Manuscript and re-check the ticked chapters in Share.
Windows says "unknown publisher"The installer isn't code-signed yet: More info → Run anyway.
